# どうぶつ どこ？ 🐱🐶🐘

2〜4歳向けの iPhone 用「どうぶつどこ？」ゲームです。
「ねこさん、どーこだ？」という声の問題を聞いて、正しい動物をタッチします。文字が読めない子どもでも、ひとりで遊べます。

## あそびかた

1. 大きな黄色い ▶ ボタンを押すとスタート
2. 声で「○○さん、どーこだ？」と問題が出る（左上の 🔊 を押すと、もう一度聞ける）
3. 正しい動物をタッチすると、動物がくるっとジャンプして紙吹雪・星・ハートが出て、「すごーい！」とほめてくれる
4. 約1秒で次の問題へ自動で進む
5. 違う動物を押しても失敗の表示は出ない。「もういっかい！」とやさしく声をかけるだけ（2回まちがえると、正解の動物がぴかぴか光ってヒントを出す）
6. 2問正解するごとに、ライオン・うさぎ・パンダ・おさる・きりん……と新しい動物が仲間入りする（全15種類）
7. 星を5つ集めると「やったー！」のごほうび演出。緑の ↻ ボタンで次のラウンドへ

## 特長

- HTML / CSS / JavaScript のみ（外部ライブラリなし、ビルド不要）
- 声は Web Speech API の日本語読み上げ、効果音は Web Audio API で合成（音声ファイルなし）
- iPhone 縦画面に最適化（ノッチ・ホームバーのセーフエリアに対応）
- 背景で雲・太陽・ちょうちょ・草花・きらきらが動く
- 誤操作対策：ピンチズーム・ダブルタップズーム・長押しメニュー・スクロールを無効化

## ファイル構成

```
index.html     画面（スタート / ゲーム / ごほうび）
style.css      デザインとアニメーション
js/sound.js    効果音
js/voice.js    日本語の読み上げ
js/fx.js       紙吹雪・星・ハートのエフェクト（canvas）
js/game.js     ゲームの進行
.nojekyll      GitHub Pages で Jekyll 処理を無効化
```

## GitHub Pages で公開する

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にする
3. ブランチ `main`、フォルダ `/ (root)` を選んで **Save**
4. 数分後に `https://<ユーザー名>.github.io/animal-touch-game/` で遊べます

iPhone の Safari で開き、共有ボタン →「ホーム画面に追加」すると、アプリのように全画面で遊べます。

### 音が出ないとき

- iPhone の消音モード（側面のスイッチ）を解除し、音量を上げてください
- 読み上げの声は「設定 → アクセシビリティ → 読み上げコンテンツ → 声 → 日本語」で変えられます（Kyoko などがおすすめ）

## ローカルで試す

`index.html` をブラウザで開くだけで動きます。
